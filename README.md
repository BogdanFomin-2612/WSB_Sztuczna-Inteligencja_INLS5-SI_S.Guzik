# Projekt zaliczeniowy

Przedmiot zaliczamy projektem oddanym w Moodle i zaprezentowanym na ostatnich zajęciach **(12.01.2027)**. 

* **Zespoły:** 2–3 osobowe.
* **Projekt:** Działający program w Pythonie, który wykorzystuje co najmniej dwie metody z semestru (np. reprezentacja wiedzy + reguły, algorytm genetyczny, logika rozmyta, sieć neuronowa).

### Do oddania:
* Repozytorium Git z instrukcją uruchomienia (`README.md`)
* Krótki raport (3–5 stron: problem, metoda, wyniki, wnioski)
* Prezentacja (10 minut)

---

## Przykładowe tematy:
* System ekspercki doradzający wybór laptopa (reguły + wnioskowanie wstecz)
* Planer rozkładu zajęć optymalizowany algorytmem genetycznym
* Sterownik rozmyty klimatyzacji lub parkowania
* Klasyfikator gatunków muzyki siecią neuronową z bazą wiedzy o gatunkach
* Chatbot FAQ uczelni z ontologią pojęć (sieć semantyczna) i dopasowaniem pytań

---

## Na koniec zajęć (40 min):
1. Utwórzcie zespół i wybierzcie temat (może być własny — do akceptacji prowadzącego).
2. Załóżcie repozytorium, dodajcie prowadzącego, wrzućcie `README.md` z tematem i składem zespołu.
3. Wklejcie w Moodle link do repozytorium i jednozdaniowy opis problemu.
